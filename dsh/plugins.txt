# dsh profile plugin set — the reproducible install list for `dsh plugin add`.

# Format: one install spec per line, `#` comments and blank lines ignored.
# Replayed by dsh/install.sh into the web profile. Keep this file as the source
# of truth for which plugins a fresh machine gets: the live profile's
# package.json is machine state (pnpm rewrites it atomically, so it cannot be
# symlinked into the repo) and is not the record of intent.
#
# Regenerate after installing a plugin in the UI:
#   node -e 'const p=require(process.env.HOME+"/.dsh/profiles/web/package.json");
#            for (const [k,v] of Object.entries(p.dependencies).sort())
#              console.log(v.startsWith("link:") ? "# LOCAL " + k : k + "@" + v)'
#
# Order does not matter for `dsh plugin add`; bundles are composed by the
# profile manifest's dsh.profile.bundles afterwards.
#
# Pinned deliberately where upstream tracks @latest or a moving branch.
